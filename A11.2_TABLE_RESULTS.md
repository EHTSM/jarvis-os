## T1 — `.aud-table` overflowed the viewport — **FIXED**

**Reproduced at 390 × 844:**

```
Tables @ AI Orchestration: w=470 left=16 right=486 inViewport=FALSE overflowX=visible
```

The table's right edge sat at **486px in a 390px viewport — 96px outside**, with
no scroll container.

**Root cause.** `.aud-table` declares `width: 100%` but its column content sets a
larger intrinsic width, and the table had **no wrapper**, so it pushed the
document instead of scrolling.

**Recovered pattern.** The `-table-wrap` idiom that already exists in four
files — `.tw-perms-table-wrap`, `.ec-table-wrap`, `.pp-rev-table-wrap`,
`.rd-table-wrap`:

```css
.aud-table-wrap { overflow-x: auto; }
```

Both `.aud-table` instances were wrapped. **The table itself is unchanged** — no
column, density or typography edits.

**Verified after:**

```
Tables @ AI Orchestration: w=358 left=16 right=374 inViewport=TRUE overflowX=auto
```

`right` 486 → **374**; `inViewport` false → **true**; `overflow-x` visible → **auto**.
