## Why the 29 were not converted

`EmptyState` is **variant-driven**. Each usage requires a catalogue entry:

```
what is this?          → title
why should I care?     → description
what should I do next? → steps[] (2–3 concrete actions) + primaryAction
```

Substituting the component **without** authoring those fields produces a shell
that says *less* than the literal it replaced — a regression measured in user
value, not an improvement.

The mission's rule is explicit: *only category A may be recovered* — and
recovery here means reusing the component **correctly**, which requires 29
pieces of surface-specific copy. That is authoring, not pattern recovery.

Converting them to hit a number would be exactly the "convert merely for
numerical consistency" the mission forbids.
