## Risk severity legend

- **HIGH:** could cause real data exposure, real financial loss, or a real security compromise if exploited/triggered.
- **MEDIUM:** degrades a real feature or creates a real but bounded exposure; not an immediate crisis.
- **LOW:** narrow, cosmetic, or requires an unlikely combination of conditions.
- **UNKNOWN:** genuinely not assessable with the tools/time/infrastructure available in this session — stated as unknown rather than guessed.

## Top 3 risks requiring a decision before any launch beyond a fully-trusted internal team

1. **R1 (SSRF)** — the only HIGH-severity item with zero mitigation and a real, live-confirmed reachable exploit path.
2. **R2 (tenant isolation)** — architectural; the true blocker for any multi-tenant launch, requires a scoped follow-up project, not a quick fix.
3. **R5 (email verification broken)** — a HIGH-severity blocker specifically for the closed-beta launch this mission's `launch-readiness.md` otherwise gives a GO to; provisioning one credential resolves it.
