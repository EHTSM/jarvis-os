## Summary

**(2026-07-25):**
- **Live-CONNECTED with real, valid credentials (2):** Telegram, and `ai:groq` (imported this session, not in the original 15-service list but now the working default in the AI provider fallback chain).
- **Configured but credential VALUE is genuinely rejected by the live API (2):** OpenAI (401 — was reported CONNECTED on 2026-07-17, no longer valid), Razorpay (401 — was reported CONNECTED on 2026-07-17, no longer valid).
- **Configured but credential VALUE is wrong in a previously-diagnosed way (1):** WhatsApp — operator action needed (correct `WA_PHONE_ID`), not a code fix.
- **OAuth credential present, honestly unverifiable without a live consent redirect (1):** GitHub's `auth:github` (OAuth client secret imported this session) — this is CONFIGURED_UNVERIFIED, a genuine status, not a failure.
- **Code-ready, credentials genuinely missing from this environment (9, includes GitHub's separate PAT):** GitHub PAT (`git:github`, blocks 75 companies), Google (partial — client ID present, secret missing), Anthropic, Gemini, Cloudflare (blocks 75 companies), Supabase, Notion, Slack, Discord.
- **Not configurable at all in this environment — external business/legal step required (2):** Apple (Developer Program membership + Team ID + signing cert), Windows (code-signing certificate purchase).

No credential in this list was found to be both "configured" and silently broken in a way that would surprise an operator — every gap is either a plainly absent `.env` value (visible via `.env.example`'s own documentation), a previously-diagnosed wrong-value case with a known fix path (WhatsApp), or a freshly-confirmed-this-session credential-value rejection (OpenAI, Razorpay) that requires an operator to supply a new valid value — none require a code change.

**Note on drift:** OpenAI's and Razorpay's status changed between 2026-07-17 and 2026-07-25 despite no code change — the credential VALUES themselves stopped being accepted by the live provider APIs sometime in between (expiry, rotation, or revocation on the provider side). This is exactly the kind of drift `IntegrationCenter.jsx`'s newly-added rotation/last-verified UI (Phase 16, this session) is meant to surface to the founder going forward.
