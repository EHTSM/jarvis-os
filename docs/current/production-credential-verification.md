## Summary

- **Live-CONNECTED with real, valid credentials (3):** OpenAI, Razorpay, Telegram.
- **Configured but credential VALUE is wrong (1):** WhatsApp — operator action needed (correct `WA_PHONE_ID`), not a code fix.
- **Code-ready, credentials genuinely missing from this environment (9):** GitHub, Google (partial — client ID present, secret missing), Anthropic, Gemini, Cloudflare, Supabase, Notion, Slack, Discord.
- **Not configurable at all in this environment — external business/legal step required (2):** Apple (Developer Program membership + Team ID + signing cert), Windows (code-signing certificate purchase).

No credential in this list was found to be both "configured" and silently broken in a way that would surprise an operator — every gap is either a plainly absent `.env` value (visible via `.env.example`'s own documentation) or, for WhatsApp, a specific, previously-diagnosed wrong-value case with a known fix path.
