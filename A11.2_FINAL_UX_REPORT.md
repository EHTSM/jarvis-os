## The two fixes

### F3 — every silent mutation now reports its real reason

Fifteen user actions (pause, cancel, reject, dismiss, undo, acknowledge, replay,
evolve, promote, benchmark, **switch workspace**, **create workspace**) failed
with no feedback. Each was recovered using **the mechanism already in its own
file** — `setError`, `setStatus`, or that file's existing result-error shape.

**Root cause found mid-recovery:** four files shared a private `API()` helper
returning `r.json()` with **no status check**, so a 403 body arrived as data and
the `catch` only fired on network failure — the same defect class as A.11 F1.
Recovered to mirror the canonical `_client.js`: preserve the backend message,
attach the status, throw.

The most severe was `WorkspaceSwitcher`: switching or creating a workspace
failed **silently**. It now renders the backend's reason using existing semantic
tokens.

### T1 — the one rendered table overflowed mobile

`.aud-table` measured `right=486` in a **390px** viewport — 96px outside, with
`overflow-x: visible` and no wrapper. Recovered with the `-table-wrap` idiom
already used in four other files. Verified: `right` 486 → **374**,
`inViewport` false → **true**.

## Honest negatives

These are the parts most likely to be glossed over, so they are stated plainly:

**R2 was not fixed.** Three hypotheses were tested against live measurement —
`min-width: 0` on the scrollable rows' children, on `.cmd-layout`, and on
`.cmd-root`. **None moved the number** (465px, unchanged). All three were
**reverted**, because leaving CSS that asserts a fix which did not happen is
worse than an open finding.

**F5's "66" was too generous.** Re-classifying against the mission's own A–D
criteria shows only **29** are genuinely convertible: 17 are filtered-search
results where an onboarding EmptyState would be *wrong*, 8 carry interpolated
context, 8 already name a next action, 4 are transient states.

**F4 merged nothing, deliberately.** 58 of 59 systems are live and **zero** are
true duplicates. The 12 that look mergeable span 21 distinct paddings — picking
one changes 11 surfaces' visual density, which is a design decision, not a
recovery.

**Mobile dialogs measured nothing.** The triggers are not rendered at mobile
widths and the data-driven dialogs need workspace membership. Reported as
NOT MEASURED rather than inferred from B19's desktop evidence.
