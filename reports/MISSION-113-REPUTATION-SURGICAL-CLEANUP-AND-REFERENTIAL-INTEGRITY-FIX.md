## 15. Unexpected Finding — Disclosed Honestly, Not a Gate Failure

**`data/civilization/context.json` changed** (SHA-256 `0a984a4b...` → `b91fb2e9...`), which was
**not** in this mission's authorized scope (authorization covered `reputation.json` deletion and the
`civilizationState.cjs` code fix only; `context.json` was never mentioned).

**Root cause, traced precisely:** this mission's own Phase 5 check #10 (§11) called
`getCivilizationDashboard()` live to verify the repaired dataset. That function internally calls
`getCivilizationHealth()` (`civilizationState.cjs:842`), which — as a documented side effect,
unrelated to anything this mission changed — recomputes and persists an updated `lastSync` timestamp
(and derived `healthScore`/`membersCount` snapshot fields) to `context.json` via `_save("context")`
(line 875). This is pre-existing behavior of a **read function with a caching side effect**, not
something this mission introduced or could have avoided while still performing the dashboard
verification the brief itself required (item 10 in Phase 5's checklist).

**Why this is not treated as a gate failure:**
1. `context.json` is not a source-of-truth data file — it is a derived/computed cache (`phase`,
   `membersCount`, `healthScore`, `epoch`, `lastSync`), gitignored, with no dedicated backup ever
   taken by any prior mission (Missions 105/108/111 only ever hashed it as a "no-touch baseline," never
   diffed its content) — meaning this mission has no way to prove or disprove whether its exact
   content already changed identically during Mission 111/112's own verification calls.
2. The changed fields (`membersCount: 4`, matching the live registry exactly) reflect **correct
   current state**, not corrupted or fabricated data.
3. No other civilization data file, no economy balance, no registry member, and no reputation record
   was affected by this side effect.
4. The brief's own Phase 5 required exactly the dashboard-verification call that triggered this — an
   unavoidable consequence of honestly performing the requested check, not a shortcut or convenience.

**This finding is disclosed here in full, not hidden or minimized**, consistent with this mission's
own "no unexpected findings suppressed" obligation. No further action was taken on it (no revert
attempted, since `context.json`'s pre-change exact content was never captured and is not
reconstructible, and since a revert attempt itself would be a second, unauthorized mutation).
